# Town Of RootTown
Town Of RootTown is a simplistic city builder where you need to expand your underground colony up to the surface before the Great Collapse, and hopefully not kill everybody in the process.

## Info
- Made in Godot 4.7
- Made for [Cozy Fall Jam 2026](https://itch.io/jam/cozy-fall-jam-2026/rate/5063084)
- Features 6 different buildings
- Procedural tree root generation using perlin worms

## Controls
WASD / Arrow keys to move.

Click to select

## Development
- To setup a dev build of the project, clone the repo and click Import in godot 4.7, then select the repo.
